# Understanding the Project

## Cyber Security Placement – Adversary Test Automation

## What is the project?

The project is about investigating how cybersecurity testing and
adversary behaviours can be automated within a safe and isolated
laboratory environment.

The project will explore how selected security tests can be performed
repeatedly and automatically.

The project will also investigate how AI and Large Language Models (LLMs)
can be used to generate test cases and how these tests compare with
manually written test cases.

## What will I do?

### 1. Set Up the Lab

Prepare the authorised and isolated environment and the systems required
for testing.

### 2. Understand the Threat and Select Tests

Learn about adversary behaviours and use the MITRE ATT&CK framework to
help identify and select suitable tests.

### 3. Perform Security Tests

Run selected security and adversary tests within the authorised
laboratory environment.

### 4. Automate the Tests

Investigate how selected tests can be made repeatable and automated.

### 5. Record and Analyse Results

Collect test results and relevant telemetry to understand what happened
during testing.

### 6. Use AI / LLMs

Investigate how AI and LLMs can be used to generate cybersecurity test
cases.

### 7. Compare and Evaluate

Compare AI-generated test cases with manually written test cases and
evaluate the effectiveness and limitations of the approach.

### 8. Document the Work

Document the testing approach, results, findings and limitations.
